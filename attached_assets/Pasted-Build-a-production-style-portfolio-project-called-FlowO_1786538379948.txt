Build a production-style portfolio project called FlowOps.

FlowOps is an AI-assisted internal request and workflow management platform for a company.

Goal:
Employees submit internal requests such as:
"My SAP account is locked and I need access before tomorrow."

The system should:
1. accept a request
2. classify it automatically
3. extract structured information
4. calculate a priority
5. store everything
6. display requests in a professional dashboard
7. expose REST API endpoints
8. support future webhook/n8n integrations

Required backend:
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- REST API
- environment variables
- clean modular architecture

Required application features:
- Submit a request
- Request title
- Description
- Requester
- Category
- Priority
- Status
- Created timestamp
- Update status
- Filter requests
- Search requests
- Request detail page
- Dashboard statistics

Categories:
- ACCESS
- HARDWARE
- SOFTWARE
- NETWORK
- SECURITY
- OTHER

Statuses:
- NEW
- CLASSIFIED
- IN_PROGRESS
- RESOLVED
- CLOSED

AI classification:
Create a service abstraction for an LLM provider.
If no API key is configured, provide a deterministic local fallback classifier so the application remains fully runnable.

The classifier should return structured JSON such as:
{
  "category": "ACCESS",
  "priority": "HIGH",
  "system": "SAP",
  "summary": "SAP account requires unlock"
}

Frontend:
Create a clean professional responsive dashboard.
Do not make it look like a toy/demo application.

Engineering requirements:
- Dockerfile
- docker-compose.yml with PostgreSQL
- requirements.txt or pyproject.toml
- README.md
- .env.example
- automated tests
- health endpoint
- API error handling
- seed/sample data
- Swagger/OpenAPI support
- sensible logging

README must explain:
- business problem
- architecture
- technologies
- setup
- Docker setup
- API usage
- testing
- screenshots section
- future n8n/webhook integration

Do not use fake enterprise claims.
This is a personal portfolio project.

First create a plan, then implement the complete runnable MVP.
